# 使用说明

本文档说明如何打开和体验当前本地 dashboard 产品。

## 1. 最快打开方式

在项目根目录双击：

```text
start_dashboard.bat
```

启动后，在浏览器打开：

```text
http://localhost:8501
```

如果浏览器没有自动打开，手动复制上面的地址即可。

## 2. 命令行打开方式

也可以在项目根目录运行：

```bash
python -m streamlit run app.py --server.port 8501
```

如果本机使用虚拟环境，先激活环境：

```bash
.venv\Scripts\activate
python -m streamlit run app.py --server.port 8501
```

## 3. 第一次使用流程

1. 打开 `http://localhost:8501`。
2. 在左侧切换 `Language / 语言`，选择 English 或中文。
3. 先看页面顶部状态标签：records、data mode、analysis year、data updated、filters、source，用它确认当前分析范围。
4. 在 `Home / Start` 查看当前数据状态、数据健康和推荐任务入口。
5. 每个页面标题下方都有第一屏说明，先确认该页回答的问题，再操作控件。
6. 如果当前数据不是官方缓存数据，进入 `Data Intake` 点击 `Restore official cached data`。
7. 使用左侧全局筛选选择 district、usage、age band、risk level。
8. 从 `Home / Start` 或左侧导航进入 `Portfolio Overview` 查看整体楼龄和风险结构。
9. 进入 `Spatial Dashboard` 查看地图。默认先看区域分级着色；需要查看单栋资产时再开启 `Building points`，需要监管记录点位时开启 `MBIS notice layer`。
10. 进入 `District Benchmark` 查看区域维护优先级排名。
11. 进入 `Regulatory Signals` 查看 MBIS 监管通知信号。
12. 如需 DeepSeek / OpenAI，进入 `Admin / Settings` 配置 API Key、Base URL、Model name 并测试连接。
13. 进入 `AI Report Studio` 确认报告范围、数据版本、模型版本和生成方式，生成摘要并导出 Markdown / HTML。
14. 进入 `Method & QA` 生成并下载完整导出包 ZIP。

## 4. 关键页面用途

| 页面 | 用途 |
| --- | --- |
| Home / Start | 数据状态、推荐任务入口、可用导出物 |
| Data Intake | 数据源、质量摘要、用户 CSV 上传、恢复官方缓存 |
| Portfolio Overview | 全港或筛选范围的楼龄、用途、风险概览 |
| Spatial Dashboard | 区域分级着色、建筑点位、MBIS notice 图层、点位抽样状态 |
| District Benchmark | 区域 priority ranking 和指标对比 |
| Use & Typology | 用途和建筑类型分析 |
| Regulatory Signals | MBIS notice 匹配率、密度和点位 |
| AI Report Studio | 报告范围确认、模板或 LLM 摘要、Markdown / HTML 报告导出 |
| Admin / Settings | Template / DeepSeek / OpenAI / Local 配置与连接测试 |
| Method & QA | 方法、质量、限制说明和完整导出包 |

## 5.1 Spatial Dashboard 地图使用

`Spatial Dashboard` 默认优先展示 district choropleth，适合先判断哪些区域更值得关注。

- `District choropleth`：区域聚合图层，可在 priority index、median age、50+ share、MBIS notices per 1,000 buildings 之间切换。
- `Building points`：单栋建筑点位，按 risk level 着色；全量数据下默认关闭，开启后按 `Building point cap` 固定抽样并使用 clustering。
- `MBIS notice layer`：监管通知点位，按当前筛选范围内可关联建筑过滤；点位 tooltip 会注明监管记录不是结构缺陷结论。
- `Layer Display Status`：显示每个图层当前是关闭、完整筛选集合，还是聚合抽样。

## 6. 刷新官方数据

使用已有官方缓存重新构建：

```bash
python -m src.pipeline.build_all --use-cache --analysis-year 2026
```

强制重新下载官方数据：

```bash
python -m src.pipeline.build_all --force --analysis-year 2026
```

Dashboard 内也可以在 `Data Intake` 页面点击 `Restore official cached data`。

## 7. 生成完整交付包

命令行方式：

```bash
python -m src.pipeline.export_results
```

Dashboard 方式：

```text
Method & QA -> Generate full export package -> Download export package ZIP
```

## 8. 验证产品是否正常

运行：

```bash
python -m src.pipeline.product_readiness
```

通过后会更新：

```text
outputs/exports/product_readiness.json
outputs/exports/product_readiness.md
```

## 9. 生成演示截图

首次使用截图脚本前安装浏览器：

```bash
python -m playwright install chromium
```

生成标准 dashboard 截图：

```bash
python -m src.pipeline.capture_dashboard_screenshots --base-url http://localhost:8501 --output-dir outputs/screenshots
```

演示流程和截图清单见：
